## Chain-of-Thought (GLM5 Reasoning)

### Understanding the Core Concepts

**What are nodeType, nodeName, and nodeValue?**

These are fundamental DOM Level 1 properties that apply to ALL nodes in the DOM tree:

1. **nodeType** (read-only integer)
   - Numeric constant indicating the node's type
   - Element Node = 1, Text Node = 3, Comment = 8, Document = 9, etc.
   - Critical for conditional logic when traversing mixed node types
   - More reliable than checking instanceof for cross-frame compatibility

2. **nodeName** (read-only string)
   - Returns different values based on node type
   - Elements: uppercase tag name (e.g., "DIV", "SPAN")
   - Text nodes: "#text"
   - Comment nodes: "#comment"
   - Document: "#document"
   - Always uppercase for elements, ensuring case-insensitive comparison

3. **nodeValue** (read/write string or null)
   - Returns/sets the value of the node
   - Text/Comment/CDATA: the text content
   - Elements/Document: null (use textContent instead)
   - Processing instructions: the content
   - Can be modified for text/comment nodes

### Requirements Analysis

**Functional Requirements:**
- Parse and visualize DOM tree structure
- Display all three properties for any selected node
- Support real-time updates as DOM changes
- Provide search and filtering capabilities
- Handle all node types (elements, text, comments, etc.)
- Export functionality for documentation

**Technical Requirements:**
- Efficient traversal without blocking UI
- Memory-efficient storage of node references
- Responsive design for large DOM trees
- Cross-browser compatibility
- Accessibility for keyboard navigation

### Design Decisions

**1. Data Structure for DOM Tree**

```javascript
// Store minimal information to avoid memory leaks
{
  node: Node,           // Reference to actual DOM node
  nodeType: Number,     // Cached for performance
  nodeName: String,     // Cached to avoid repeated calls
  nodeValue: String,    // Cached, null for elements
  children: Array,      // Child node wrappers
  expanded: Boolean     // UI state for tree view
}
```

**Why this structure?**
- Caching properties reduces DOM API calls
- Separate UI state from node data
- Easy to serialize for export
- Memory-conscious by storing only needed data

**2. Traversal Strategy**

Using TreeWalker API for efficient DOM traversal:
- Native browser API optimized for DOM navigation
- Can filter by nodeType during traversal
- Avoids recursion depth issues with large DOMs
- Provides iterative interface for batch processing

**Alternative considered:** Recursive walkChildNodes()
- Rejected: Can hit stack limits on deep DOMs
- Rejected: Harder to pause/resume for large trees

**3. Rendering Approach**

Virtual scrolling for performance:
- Only render visible nodes in viewport
- Maintain smooth scrolling with large trees
- Use IntersectionObserver for lazy loading

**4. Real-time Updates**

MutationObserver for change detection:
- Efficiently monitor DOM changes
- Update only affected tree branches
- Debounce rapid successive mutations

### Edge Cases to Handle

1. **Null nodeValue**
   - Elements return null for nodeValue
   - Display "N/A" or explanation tooltip
   - Guide users to textContent for elements

2. **Whitespace-only text nodes**
   - Common in formatted HTML
   - Option to hide/show these
   - Important for accurate DOM representation

3. **Cross-origin iframes**
   - Cannot access internal DOM
   - Show as restricted node type
   - Provide informative message

4. **SVG/MathML elements**
   - nodeName might be lowercase in some browsers
   - Handle namespace-aware elements
   - Test with mixed HTML/SVG content

5. **Shadow DOM**
   - Shadow roots have nodeType 11 (DOCUMENT_FRAGMENT_NODE)
   - Need special handling for shadow trees
   - Indicate closed vs open shadow roots

6. **Dynamic content**
   - AJAX-loaded content
   - Template elements (not rendered)
   - Document fragments (detached nodes)

### Performance Considerations

1. **Debounce search/filter operations**
   - User typing triggers many events
   - Wait 300ms before processing
   - Cancel previous pending operations

2. **Limit initial tree depth**
   - Don't render entire tree at once
   - Load children on-demand when expanding
   - Show node count badges for collapsed branches

3. **Use requestAnimationFrame**
   - Smooth UI updates
   - Batch DOM reads/writes
   - Avoid layout thrashing

4. **WeakMap for node metadata**
   - Avoid memory leaks from node references
   - Automatic cleanup when nodes removed
   - Store UI state without preventing GC

### Why These Design Choices?

**TreeWalker over custom recursion:**
- Browser-optimized native implementation
- Built-in filtering capabilities
- Iterative approach prevents stack overflow

**Virtual scrolling over full render:**
- Handles 10,000+ node trees smoothly
- Reduces memory footprint
- Better mobile performance

**MutationObserver over polling:**
- Event-driven, not time-based
- Only processes actual changes
- Detailed mutation records for smart updates

**WeakMap for node data:**
- Automatic memory management
- No manual cleanup needed
- Safe for long-running applications

**Separate display logic from data:**
- Easier to test each component
- Can swap renderers (tree view, flat list, etc.)
- Clear separation of concerns

        class AppState {
            constructor() {

                    comments: 0,
                    maxDepth: 0
                };

            /**
             * Generate unique ID for a node
             * Uses WeakMap to avoid memory leaks
             */
            generateNodeId(node) {
                if (!this.nodeIdMap) {
                    this.nodeIdMap = new WeakMap();
                    this.nextId = 0;
                }
                
                if (!this.nodeIdMap.has(node)) {
                    this.nodeIdMap.set(node, `node_${this.nextId++}`);
                }
                
                return this.nodeIdMap.get(node);
            }

            /**
             * Reset state for fresh DOM scan
             */
            reset() {
                this.nodes.clear();
                this.selectedNodeId = null;
                this.expandedNodes.clear();
                this.stats = {
                    total: 0,
                    elements: 0,
                    text: 0,
                    comments: 0,
                    maxDepth: 0
                };
            }
        }

        // ==========================================
        // DOM Walker - Efficient Tree Traversal
        // ==========================================

        class DOMWalker {
            constructor(rootNode) {
                this.root = rootNode || document.documentElement;
                this.walker = null;
            }

            /**
             * Create TreeWalker for efficient DOM traversal
             * @param {number|null} nodeTypeFilter - Optional node type to filter
             * @returns {TreeWalker}
             */
            createWalker(nodeTypeFilter = null) {
                // TreeWalker is a native API optimized for DOM traversal
                // More efficient than recursive childNodes iteration
                const whatToShow = nodeTypeFilter 
                    ? NodeFilter.SHOW_ALL 
                    : NodeFilter.SHOW_ALL;

                const filter = nodeTypeFilter 
                    ? {
                        acceptNode: (node) => {
                            return node.nodeType === nodeTypeFilter 
                                ? NodeFilter.FILTER_ACCEPT 
                                : NodeFilter.FILTER_SKIP;
                        }
                    }
                    : null;

                this.walker = document.createTreeWalker(
                    this.root,
                    whatToShow,
                    filter,
                    false // Entity reference expansion (deprecated)
                );

                return this.walker;
            }

            /**
             * Walk through DOM and collect node information
             * Uses iterative approach to avoid stack overflow
             * @param {Function} callback - Called for each node
             * @param {number} batchSize - Nodes to process before yielding
             */
            walk(callback, batchSize = 100) {
                this.createWalker();
                let count = 0;
                let node = this.walker.currentNode;

                while (node) {
                    callback(node);
                    count++;

                    // Yield to main thread periodically to prevent UI blocking
                    if (count % batchSize === 0) {
                        // Use setTimeout to yield, then continue
                        // In production, would use requestIdleCallback
                    }

                    node = this.walker.nextNode();
                }
            }

            /**
             * Build hierarchical tree structure
             * Returns nested objects representing DOM tree
             * @param {number} maxDepth - Maximum depth to traverse
             * @returns {Object} Tree structure
             */
            buildTree(maxDepth = 50) {
                const buildNode = (node, depth = 0) => {
                    // Base case: stop at max depth
                    if (depth > maxDepth) {
                        return null;
                    }

                    // Create node wrapper with cached properties
                    const wrapper = {
                        node: node,
                        nodeType: node.nodeType,
                        nodeName: node.nodeName,
                        nodeValue: node.nodeValue,
                        depth: depth,
                        children: []
                    };

                    // Recursively process child nodes
                    // Note: Using childNodes (not children) to include text/comment nodes
                    const childNodes = node.childNodes;
                    for (let i = 0; i < childNodes.length; i++) {
                        const childWrapper = buildNode(childNodes[i], depth + 1);
                        if (childWrapper) {
                            wrapper.children.push(childWrapper);
                        }
                    }

                    return wrapper;
                };

                return buildNode(this.root);
            }
        }

        class NodeTree {
            constructor(container, state) {
                this.container = container;
                this.state = state;
                this.onNodeSelect = null; // Callback for node selection
            }

            /**
             * Render the complete tree view
             * @param {Object} treeData - Hierarchical tree data
             */
            render(treeData) {
                this.container.innerHTML = '';
                
                if (!treeData) {
                    this.container.innerHTML = '<p style="padding: 16px; color: var(--text-secondary);">No nodes to display</p>';
                    return;
                }

                const treeRoot = this.renderNode(treeData, true);
                this.container.appendChild(treeRoot);
            }

            /**
             * Render a single node and its children
             * @param {Object} nodeData - Node wrapper object
             * @param {boolean} isRoot - Is this the root node?
             * @returns {HTMLElement}
             */
            renderNode(nodeData, isRoot = false) {
                const nodeId = this.state.generateNodeId(nodeData.node);
                this.state.nodes.set(nodeId, nodeData);

                // Create node container
                const nodeEl = document.createElement('div');
                nodeEl.className = `tree-node ${isRoot ? 'root' : ''}`;
                nodeEl.setAttribute('role', 'treeitem');
                nodeEl.setAttribute('aria-expanded', 'false');

                // Create node item (clickable row)
                const itemEl = document.createElement('div');
                itemEl.className = 'node-item';
                itemEl.setAttribute('tabindex', '0');
                itemEl.setAttribute('data-node-id', nodeId);

                // Expand/collapse button for nodes with children
                const hasChildren = nodeData.children && nodeData.children.length > 0;
                const expandBtn = document.createElement('button');
                expandBtn.className = `expand-btn ${hasChildren ? '' : 'hidden'}`;
                expandBtn.textContent = '▶';
                expandBtn.setAttribute('aria-label', hasChildren ? 'Expand node' : '');
                itemEl.appendChild(expandBtn);

                // Node icon based on type
                const iconEl = document.createElement('span');
                iconEl.className = 'node-icon';
                iconEl.textContent = NODE_ICONS[nodeData.nodeType] || NODE_ICONS.default;
                itemEl.appendChild(iconEl);

                // Node name
                const nameEl = document.createElement('span');
                nameEl.className = 'node-name';
                nameEl.textContent = nodeData.nodeName;
                itemEl.appendChild(nameEl);

                // Node type badge
                const badgeEl = document.createElement('span');
                const typeClass = this.getTypeClass(nodeData.nodeType);
                badgeEl.className = `node-type-badge ${typeClass}`;
                badgeEl.textContent = NODE_TYPES[nodeData.nodeType] || 'Unknown';
                itemEl.appendChild(badgeEl);

                // Children count badge
                if (hasChildren) {
                    const countEl = document.createElement('span');
                    countEl.className = 'children-count';
                    countEl.textContent = `(${nodeData.children.length})`;
                    itemEl.appendChild(countEl);
                }

                // Event listeners
                itemEl.addEventListener('click', (e) => {
                    e.stopPropagation();
                    this.handleNodeClick(nodeId, nodeEl, expandBtn);
                });

                itemEl.addEventListener('keydown', (e) => {
                    if (e.key === 'Enter' || e.key === ' ') {
                        e.preventDefault();
                        this.handleNodeClick(nodeId, nodeEl, expandBtn);
                    }
                });

                expandBtn.addEventListener('click', (e) => {
                    e.stopPropagation();
                    this.toggleNode(nodeId, nodeEl, expandBtn);
                });

                nodeEl.appendChild(itemEl);

                // Render children (initially hidden)
                if (hasChildren) {
                    const childrenContainer = document.createElement('div');
                    childrenContainer.className = 'children-container';
                    childrenContainer.style.display = 'none';

                    nodeData.children.forEach(childData => {
                        const childNode = this.renderNode(childData);
                        childrenContainer.appendChild(childNode);
                    });

                    nodeEl.appendChild(childrenContainer);
                }

                return nodeEl;
            }

            /**
             * Handle node click: select and optionally expand
             */
            handleNodeClick(nodeId, nodeEl, expandBtn) {
                // Deselect previous
                const prevSelected = this.container.querySelector('.node-item.selected');
                if (prevSelected) {
                    prevSelected.classList.remove('selected');
                }

                // Select current
                const itemEl = nodeEl.querySelector('.node-item');
                itemEl.classList.add('selected');
                this.state.selectedNodeId = nodeId;

                // Trigger callback
                if (this.onNodeSelect) {
                    const nodeData = this.state.nodes.get(nodeId);
                    this.onNodeSelect(nodeData);
                }

                // Auto-expand on click
                if (!expandBtn.classList.contains('hidden')) {
                    this.toggleNode(nodeId, nodeEl, expandBtn);
                }
            }

            /**
             * Toggle node expansion
             */
            toggleNode(nodeId, nodeEl, expandBtn) {
                const childrenContainer = nodeEl.querySelector('.children-container');
                if (!childrenContainer) return;

                const isExpanded = this.state.expandedNodes.has(nodeId);

                if (isExpanded) {
                    childrenContainer.style.display = 'none';
                    expandBtn.classList.remove('expanded');
                    this.state.expandedNodes.delete(nodeId);
                    nodeEl.setAttribute('aria-expanded', 'false');
                } else {
                    childrenContainer.style.display = 'block';
                    expandBtn.classList.add('expanded');
                    this.state.expandedNodes.add(nodeId);
                    nodeEl.setAttribute('aria-expanded', 'true');
                }
            }

            /**
             * Get CSS class for node type badge
             */
            getTypeClass(nodeType) {
                const typeMap = {
                    1: 'element',
                    3: 'text',
                    8: 'comment',
                    9: 'document',
                    11: 'other'
                };
                return typeMap[nodeType] || 'other';
            }

            /**
             * Filter nodes by type
             * @param {string} filter - 'all' or nodeType number
             */
            filterNodes(filter) {
                const items = this.container.querySelectorAll('.node-item');
                
                items.forEach(item => {
                    const nodeId = item.getAttribute('data-node-id');
                    const nodeData = this.state.nodes.get(nodeId);
                    
                    if (filter === 'all' || nodeData.nodeType === parseInt(filter)) {
                        item.style.display = 'flex';
                    } else {
                        item.style.display = 'none';
                    }
                });
            }

            /**
             * Search nodes by name or value
             * @param {string} query - Search string
             */
            searchNodes(query) {
                if (!query) {
                    this.filterNodes(this.state.filter);
                    return;
                }

                const lowerQuery = query.toLowerCase();
                const items = this.container.querySelectorAll('.node-item');

                items.forEach(item => {
                    const nodeId = item.getAttribute('data-node-id');
                    const nodeData = this.state.nodes.get(nodeId);
                    
                    const nameMatch = nodeData.nodeName.toLowerCase().includes(lowerQuery);
                    const valueMatch = nodeData.nodeValue && 
                                       nodeData.nodeValue.toLowerCase().includes(lowerQuery);
                    
                    if (nameMatch || valueMatch) {
                        item.style.display = 'flex';
                        // Highlight matching text
                        this.highlightMatch(item, query);
                    } else {
                        item.style.display = 'none';
                    }
                });
            }

            /**
             * Highlight matching text in node item
             */
            highlightMatch(itemEl, query) {
                const nameEl = itemEl.querySelector('.node-name');
                const text = nameEl.textContent;
                const regex = new RegExp(`(${query})`, 'gi');
                nameEl.innerHTML = text.replace(regex, '<mark>$1</mark>');
            }
        }

        class ExportManager {
            /**
             * Export DOM structure as JSON
             * @param {Object} treeData - Tree structure
             */
            exportJSON(treeData) {
                const cleanTree = this.sanitizeForExport(treeData);
                const json = JSON.stringify(cleanTree, null, 2);
                this.download(json, 'dom-structure.json', 'application/json');
            }

            /**
             * Export as formatted text
             */
            exportText(treeData) {
                const lines = [];
                this.buildTextTree(treeData, lines, 0);
                const text = lines.join('\n');
                this.download(text, 'dom-structure.txt', 'text/plain');
            }

            /**
             * Recursively build text representation
             */
            buildTextTree(node, lines, depth) {
                const indent = '  '.repeat(depth);
                const typeStr = NODE_TYPES[node.nodeType] || 'Unknown';
                const valueStr = node.nodeValue 
                    ? `: "${node.nodeValue.substring(0, 50)}${node.nodeValue.length > 50 ? '...' : ''}"`
                    : '';
                
                lines.push(`${indent}${node.nodeName} [${typeStr}]${valueStr}`);

                if (node.children) {
                    node.children.forEach(child => {
                        this.buildTextTree(child, lines, depth + 1);
                    });
                }
            }

            /**
             * Remove circular references for JSON export
             */
            sanitizeForExport(node) {
                return {
                    nodeType: node.nodeType,
                    nodeName: node.nodeName,
                    nodeValue: node.nodeValue,
                    children: node.children 
                        ? node.children.map(c => this.sanitizeForExport(c))
                        : []
                };
            }

            /**
             * Trigger file download
             */
            download(content, filename, mimeType) {
                const blob = new Blob([content], { type: mimeType });
                const url = URL.createObjectURL(blob);
                const link = document.createElement('a');
                link.href = url;
                link.download = filename;
                link.click();
                URL.revokeObjectURL(url);
            }
        }

        /**
         * Educational Notes:
         * 
         * nodeType, nodeName, and nodeValue are part of the DOM Level 1 Core specification.
         * They apply to ALL node types in the DOM tree.
         * 
         * Key Takeaways:
         * 
         * 1. nodeType is a numeric constant (1=Element, 3=Text, 8=Comment, 9=Document)
         *    - Use for type checking in conditional logic
         *    - More reliable than instanceof across frames
         * 
         * 2. nodeName returns different values based on node type:
         *    - Elements: uppercase tag name (e.g., "DIV", "SPAN")
         *    - Text: "#text"
         *    - Comment: "#comment"
         *    - Document: "#document"
         * 
         * 3. nodeValue behavior varies by node type:
         *    - Text/Comment nodes: returns the text content (read/write)
         *    - Element nodes: returns null (use textContent instead)
         *    - Can be used to modify text/comment content
         * 
         * Performance Tips:
         * 
         * - Use TreeWalker for efficient DOM traversal
         * - Cache property values to avoid repeated DOM access
         * - Use WeakMap for node metadata to prevent memory leaks
         * - Debounce search/filter operations
         * - Consider virtual scrolling for large trees
         * 
         * Common Pitfalls:
         *
